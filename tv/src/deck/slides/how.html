How game creation works

From a spoken idea to a tested game on the TV.

Say it

The kid describes the game to the TV by voice.

Agent builds

A coding agent writes the game in a locked sandbox.

Robots play-test

Fake players run it twice. It only ships if it passes.

Everyone plays

Phones, AI players and the camera work in it automatically.

Under the hood: the TV posts the idea to our game server, a runner claims the job and runs a coding agent in a Docker sandbox, then a play-through harness runs the game twice with fake players, once with AI and camera working and once with both failing. Only a passing game is published. One and a half to three minutes end to end.
